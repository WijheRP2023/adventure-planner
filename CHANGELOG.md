# Changelog

All notable changes to Adventure Planner are documented in this file.

## 0.1.0 - 2026-07-18

Initial public release candidate.

- Added Dutch and English planner text.
- Added level- and bank-aware tasks across combat and non-combat skills.
- Added concrete methods, targets, progress counters and 30/60/90 minute rotations.
- Added automatic task continuation with manual skip, finish and stop controls.
- Added configurable daily and weekly checklists with supported automatic completion.
- Added separate run timers, sounds and location details for Farming and Birdhouse activities.
- Added local Shooting Star detection for the current scene and world.
- Added local per-profile storage for bank snapshots, Seed Vault snapshots, timers and notes.
